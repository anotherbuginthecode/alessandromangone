## You know the face. You can't name the movie.

Every film has them: the actor you have seen in twenty movies and could never name. Oh It's That Guy turns that feeling into a game. In Standard mode you get five actors and thirty seconds in total. For each face you pick the right movie out of three, wrong answers cost you three seconds, and the score rewards both accuracy and speed. Classic Challenge stretches it to eight rounds and mixes the questions: actor to movie, movie to actor, who is more popular, and true or false.

## A side project with production rules

I built it alone, in the evenings. That was not a reason to cut corners. The game had to:

- Cost close to nothing when nobody is playing.
- Answer fast from anywhere, on a phone first.
- Be rebuilt from scratch with infrastructure as code.
- Deploy on every push, with no manual steps for the client.

## Generate once, serve forever

The key decision: nothing is generated while someone plays. TypeScript pipelines pull actors, movies and popularity from the TMDB API, build complete game sets and store them in MongoDB Atlas. At play time, four Lambda functions only read. A round costs one small query, so the game stays fast and the bill stays close to zero.

Every AWS resource lives in Terraform: the S3 bucket and CloudFront distribution with origin access control, the certificate and DNS, API Gateway, the Lambda functions and their container registry. GitHub Actions builds and ships the client on every push to `main`.

## Eight months later, the agents audited it

I wrote this codebase alone, and nobody had ever reviewed it. In May 2026 I came back to it with coding agents. The first change hardened the API: the key is now added by a CloudFront function at the edge, so it never ships in the browser bundle, and every Lambda rejects requests without it.

Then I asked for an audit. The agents wrote four fix plans, one each for the backend, the client, the infrastructure and the pipelines, plus a UX evaluation. Every issue came with the file, the problem and a proposed fix, ranked by priority. Some of what they found:

- Lambda handlers with no error handling, so a database timeout became a bare 502 that the browser then reported as a CORS error.
- A CORS setup at the gateway that contradicted the one inside the functions.
- A seed script whose debug flag silently skipped every write to the database.
- Icon-only buttons with no label for screen readers.

Those plans are now the game's backlog, already sorted by what to fix first.

## Agents are the reviewer a solo project never has

Building alone is fast because nobody slows you down, and that is exactly the problem: nobody checks your work either. This project is where my workflow changed. I wrote the first version by hand in a week; agents reviewed it like a careful teammate would, and found real bugs I had shipped. Today that review step is built into everything I make, from day one instead of eight months later.
